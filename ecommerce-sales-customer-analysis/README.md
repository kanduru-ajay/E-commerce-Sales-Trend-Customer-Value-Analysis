E-commerce Sales Trend & Customer Value Analysis

Project Overview

This project performs end-to-end exploratory data analysis (EDA) on an e-commerce sales dataset to identify revenue trends, best-performing product categories, and the most valuable customers.

The objective is to turn raw sales data into meaningful business insights and actionable recommendations that can help improve revenue, customer loyalty, and marketing decisions.

Business Questions
Which months generate the highest and lowest revenue?
Which product categories contribute the most to total sales?
Who are the most valuable customers?
What percentage of revenue comes from the top 10% of customers?
How should the business improve sales and customer engagement?
Dataset Information
Data type: Simulated / Generated Data
Total orders: 2,000
Unique customers: 300
Product categories: Electronics, Fashion, Home, Books
Time period: January–December 2025
Main columns: Order ID, Order Date, Customer ID, Category, Amount

Note: The dataset is artificially generated for educational and portfolio purposes. It does not contain real customer information.

Project Workflow
1. Data Generation

Created a realistic simulated e-commerce order dataset using NumPy and Pandas.

2. Data Cleaning
Checked missing values.
Checked duplicate records.
Verified column data types.
Converted order dates into datetime format.
3. Feature Engineering

Created additional date features:

Month
Month name
Weekday
Quarter
Year
4. Revenue Trend Analysis
Calculated monthly revenue.
Measured month-over-month revenue growth.
Identified the highest and lowest revenue months.
Created monthly revenue trend visualizations.
5. Product Category Analysis
Compared total revenue by category.
Calculated average order value.
Counted orders by category.
Calculated category revenue contribution.
Created a monthly category pivot table.
6. Customer Value Analysis
Calculated total customer spending.
Identified the top 10 customers.
Calculated average customer order value.
Measured the revenue contribution of the top 10% of customers.
7. Customer Segmentation

Grouped customers into four spending segments:

Low Value
Regular
High Value
VIP
8. Pareto Analysis

Applied the 80/20 principle to investigate how much revenue is generated by the highest-spending customers.

9. Business Recommendations

Generated recommendations based on revenue performance, category contribution, and customer spending patterns.

How to Run the Project
Step 1: Clone the repository
bash
git clone https://github.com/YOUR-USERNAME/ecommerce-sales-customer-analysis.git

Step 2: Navigate to the project
bash
cd ecommerce-sales-customer-analysis

Step 3: Install dependencies
bash
pip install -r requirements.txt

Step 4: Run the analysis
bash
python ecommerce_analysis.py


The script automatically generates the dataset, analysis reports, charts, and business brief.
